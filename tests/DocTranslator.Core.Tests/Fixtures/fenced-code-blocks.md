# Code Examples

Here is a JavaScript snippet that logs a greeting to the console.

```javascript
function greet(name) {
  console.log(`Hello, ${name}! The value of x < y is ${x < y}.`);
}
```

And here is a C# snippet with angle brackets and generics that must not be translated.

```csharp
var items = new List<string> { "a", "b" };
if (items.Count > 0 && 1 < 2)
{
    Console.WriteLine("done");
}
```

Use the `dotnet build` command to compile the project.
